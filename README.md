# Sbor — Telegram-бот для сбора заявок

Готовая основа для малого бизнеса: клиент заполняет форму внутри Telegram, владелец получает уведомления и ведёт заявки в Telegram-админ-панели.

Первая версия включает пошаговую форму, статусы заявок, статистику, CSV-экспорт и настройки названия компании, услуг, контактного текста и дополнительных вопросов без изменения кода. Полная инструкция по запуску будет дополнена вместе с исходниками.

**Важно:** токены и настоящие данные клиентов в репозиторий не добавлять.
